# CamFloat 1.0.0

Windows에서 RTSP 카메라를 작고 깔끔한 창으로 볼 수 있는 무료 플레이어입니다.

## 주요 기능

- 1·2·4분할 동시 재생, 2분할 좌우·상하 전환
- 프레임 없는 창, 크기 조절, 항상 위에, 전체 투명도
- 화면 확대·전체화면, 화면별 HD/SD·음량·음소거
- 카메라 관리, 분할별 카메라 배정, 목록 내보내기·불러오기
- 재생 중 끊긴 영상의 자동 재연결
- 첫 실행에 바탕화면 바로가기·작업 표시줄 고정 선택

## 다운로드와 실행

**`CamFloat-1.0.0-win-x64.zip`을 내려받아 압축을 모두 풀고 `CamFloat.exe`를 실행하세요.**

- Windows 64비트용입니다. VLC는 별도로 설치하지 않아도 됩니다.
- `_internal`과 `licenses` 폴더를 함께 보관해주세요.
- 기존 버전은 종료한 뒤 새 배포본을 실행하세요. 저장한 카메라와 설정은 유지됩니다.
- `*.sha256`은 다운로드 파일 확인용입니다. `*.tar.xz`와 `*.tar.gz`는 개발자용 외부 라이브러리 소스이며 일반 사용자는 받을 필요가 없습니다.

## 동작 확인

### 확인된 사항

- Windows 64비트 환경에서 앱 실행과 영상·소리 재생
- 4개 영상 동시 재생, 확대·전체화면, 화면별 음량·음소거, 연결 복구
- 배포본에 포함된 재생 엔진으로 실행
- Windows 본인 확인(Windows Hello): 개발에 사용한 PC에서 직접 확인

### 다른 환경에서 사용할 때

확인 범위는 위 환경을 기준으로 하며, 그 밖의 카메라 모델과 PC·모니터 조합은 아직 모두 확인하지 않았습니다. 다른 환경에서의 사용 결과도 알려주시면 호환성 개선에 참고하겠습니다.

사용법은 앱에서 **F1**을 누르세요. 내보낸 `.camfloat` 파일은 접속 정보를 포함하며 파일을 가진 사람이 CamFloat로 열 수 있습니다.
