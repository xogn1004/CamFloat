# CamFloat

Windows용 RTSP 플레이어입니다. Python / PySide6(Qt) / libVLC로 만들고 PyInstaller로 묶었습니다. 실행 파일은 **`release\CamFloat\CamFloat.exe`**이며, 실행 PC에는 64비트 VLC media player가 설치되어 있어야 합니다. 배포할 때는 `_internal`을 포함한 해당 `CamFloat` 폴더 전체를 복사하세요. 기존 프로그램을 종료한 후 새 EXE를 실행하면 기존 설정을 읽습니다. 배포 폴더는 고정하고 변경 이력은 Git 커밋으로 관리합니다.

## 앱 도구와 화면 선택

- 창 **상단 중앙 가장자리 8px**에 약 0.3초 머물거나 `Alt` / `Alt+A`를 누르면 앱 툴바가 나타납니다. 영상 내부 이동·창 드래그에는 나타나지 않습니다. 마우스가 도구를 벗어나면 약 0.45초 뒤 숨깁니다.
- 툴바 순서: **1 · 2 · 4분할 / 항상 위 / 분할 전체화면 / 카메라 관리 / ⋯ 앱 메뉴**. 현재 분할과 항상 위 상태를 강조합니다.
- 앱 메뉴에는 투명도, 하드웨어 가속, 전체 음소거, 도움말, 최소화, 종료도 있습니다. 스크린 우클릭의 `앱 메뉴`에서도 접근할 수 있습니다.
- 각 스크린의 버튼은 **다시 연결 → 음소거·음량 → 카메라 지정 → 해당 화면 전체화면**입니다.
- 클릭하면 선택 테두리가 표시됩니다. **이미 선택된 화면을 재클릭하면 선택 자체가 해제**됩니다. 숨겨진 선택 상태는 없습니다.
- 다른 앱에서 돌아오는 첫 클릭은 기존 선택을 유지합니다. 드래그·버튼 조작·더블클릭·트리플클릭은 선택 해제로 처리하지 않습니다.
- 선택 해제는 더블클릭과 구분하기 위해 Windows의 더블클릭 판정 시간이 지난 뒤 확정합니다. 확대는 두 번째 클릭에 즉시 반응합니다.
- 선택이 없으면 `M`·`Ctrl+R`은 동작하지 않습니다. `F11`은 분할 전체화면으로 동작합니다.
- 실제 1·2·4분할 변경 시 1.8초 동안 안내합니다. 같은 분할을 다시 누르거나 SCREEN을 확대할 때는 안내하지 않습니다.

## 0.5.0 배정·연결 규칙

- **카메라 번호와 SCREEN 번호는 별개**입니다. 목록 순서를 옮겨도 카메라 번호와 저장된 SCREEN 배정은 바뀌지 않습니다.
- **1·2·4분할별로 각 SCREEN의 카메라 할당을 따로 저장**합니다. 관리창의 화면 구성 선택으로 각 배정을 편집할 수 있습니다.
- **사용 안 함:** 해당 카메라를 모든 분할의 배정에서 해제하고 빈 화면으로 둡니다. 다른 카메라로 자동 대체하지 않으며 새로 할당할 수도 없습니다.
- **다시 사용:** 각 분할에서 비어 있는 SCREEN을 번호순으로 찾아 배정합니다. 기존 카메라는 유지하며 빈칸이 없으면 미할당 상태로 둡니다.
- 첫 연결에 실패하면 자동 재연결하지 않습니다. 다시 연결 버튼·Ctrl+R로 수동 재시도합니다.
- 영상 출력이 정상적으로 열린 뒤 끊긴 경우에만 자동 재연결합니다.
- 분할에서 더블클릭 확대하면 **기존 네이티브 영상 창을 크게 표시**합니다. 다른 SCREEN도 연결·재생·개별 오디오 설정을 유지합니다. Esc 복귀 때 재연결하지 않습니다.
- 확대 중 ← / →는 **SCREEN 1 → 2 → 3 → 4**를 순환합니다. 기본 1분할에서만 사용 중인 카메라를 순환합니다.

## 0.4.0 화면 변경

- 상단 첫 줄: `SCREEN 1`과 `HD/SD` 배지. 둘째 줄: 카메라 별명. 위치 설명은 표시하지 않습니다.
- 하단 네 그룹: **다시 연결 / 음소거 아이콘·음량 / 카메라 지정 / 전체화면**. 작은 칸에서는 슬라이더를 숨기고 네 아이콘을 유지합니다. 작은 칸의 음량은 우클릭 → 이 영상 음량에서 조절합니다.
- 기본 1분할에서는 좌우 플로팅 버튼이나 **← / →**로 등록 순서에 따라 이전·다음 카메라를 순환합니다.
- 우클릭의 **이 화면의 카메라 지정**은 유지합니다. **이 카메라 수정**은 제거했으며 관리창에서 수정합니다. 주요 메뉴에 아이콘을 추가했습니다.
- 관리창 상단에서 SCREEN 1–4별 카메라를 지정할 수 있습니다. 다른 SCREEN에 있던 카메라를 지정하면 두 배정을 교환합니다. 목록의 SCREEN 열에서도 배정을 확인할 수 있습니다.

### 전체화면과 확대

| 시작 상태 / 조작 | 동작 |
| --- | --- |
| 2·4분할에서 영상 더블클릭 | 해당 SCREEN을 크게 표시하며 분할·카메라 연결 유지. 다시 더블클릭 또는 Esc로 복원 |
| 기본 1분할에서 더블클릭 | 전체화면 전환. 다시 더블클릭하면 원래 창 크기로 복원 |
| 분할 화면에서 트리플클릭 / 스크린 전체화면 버튼 | 해당 SCREEN을 확대해 전체화면으로 표시. 모든 분할 연결 유지 |
| 선택 테두리가 있는 상태에서 F11 | 선택한 SCREEN을 확대해 전체화면 |
| 선택이 없는 상태에서 F11 / 앱 툴바 전체화면 버튼 | 분할 그대로 전체화면 |
| 위 상태에서 Esc 첫 번째 | 전체화면을 유지하면서 원래 2·4분할 복원 |
| Esc 두 번째 | 전체화면 해제, 원래 창 위치·크기로 복원 |
| 기본 1분할에서 전체화면 후 Esc | 한 번에 전체화면 해제 |

전체화면 버튼이나 F11로 직접 해제하면 전체화면 진입 전의 창 크기·위치와 확대 상태로 복원합니다. Esc는 확대 복원 → 전체화면 해제 순서입니다. 기본 1분할에서는 더블클릭으로 전체화면을 전환하며 세 번째 클릭 때문에 다시 해제되지 않습니다. 전체화면 중 종료해도 일반 창 크기를 저장합니다.

## 영상 화면 조작

- 영상을 클릭하면 해당 화면에 파란 선택 테두리가 표시됩니다.
- 영상 위를 마우스로 드래그하면 전체 창이 이동합니다.
- 전체 창의 가장자리와 모서리를 드래그하면 크기가 바뀝니다.
- 우하단에 접근하면 해당 영상의 빠른 버튼이 표시됩니다. 좌상단에서는 번호·별명만, 좌우 이동 버튼 위치에서는 이동 버튼만 표시합니다. 영상 중앙을 지나갈 때는 도구가 나타나지 않습니다. 작은 창에서는 우클릭 메뉴로 음량을 조절합니다.
- 각 영상을 우클릭하면 그 화면의 카메라 지정, 화질, 음소거, 재연결 메뉴가 열립니다. 카메라 수정은 관리창에서 합니다. 2·4분할에서는 선택한 영상만 크게 볼 수 있습니다.
- 상단 앱 툴바나 앱 메뉴의 전체 화면 구성에서 1·2·4분할을 선택합니다. 2분할은 좌우, 4분할은 2×2 배치입니다.
- 항상 위 표시는 영상 창을 재생성하지 않고 변경합니다.
- `프로그램 전체 투명도` 메뉴에서 투명도를 0–80%로 조절합니다. 0%는 완전히 불투명합니다.
- 마지막 창 위치·크기, 투명도, 분할, 카메라 배치, 화질, 음량을 저장합니다.
- 2·4분할에서 더블클릭하면 해당 영상을 크게 표시합니다. 다시 더블클릭하거나 Esc를 누르면 원래 분할·순서로 복원합니다. 확대 상태에서 종료해도 확대 전 배치를 저장합니다.
- 정상 재생 후 연결 실패·종료를 감지하면 2·4·8·16·30초 간격으로 자동 재연결합니다. 15초 이상 연결 중이면 실패로 판단하며, 첫 연결 실패인 경우에는 수동 재시도만 가능합니다.
- 재생 시간 정보가 정상 제공되는 카메라는 재생 시간이 20초 넘게 멈춘 경우에도 재연결합니다. 시간 정보를 제공하지 않는 카메라는 연결 상태를 기준으로 판단합니다.
- 실제 분할 구성을 줄이면 사용하지 않는 칸의 재생은 중지합니다. 더블클릭으로 크게 보는 동안에는 가려진 칸도 계속 재생합니다. 최소화할 때도 기존 연결·소리를 유지합니다.
- EXE를 다시 열면 기존 창을 활성화합니다. 같은 설정 폴더에서는 한 프로그램만 실행합니다.

## 카메라 등록·관리

우클릭 → `등록된 카메라 관리…` → `카메라 등록`에서 한 대씩 추가합니다. 4대보다 많이 등록할 수 있으며 동시 표시는 최대 4개입니다.

등록할 때 별명을 지정하고 아래 중 하나를 선택합니다.

1. **IP / 도메인과 로그인 정보 입력**: IP 또는 도메인, 포트, 아이디, RTSP 비밀번호, 영상 경로를 입력합니다. 비밀번호 특수문자는 자동으로 처리합니다.
2. **RTSP 전체 주소 붙여넣기**: `rtsp://아이디:비밀번호@주소:포트/영상경로` 형태로 붙여넣습니다.

관리 목록의 `위로`·`아래로`는 목록과 기본 1분할의 카메라 순환 순서를 바꿉니다. 카메라 번호와 SCREEN 할당은 유지합니다. 상단의 `배정 편집할 화면 구성`에서 1·2·4분할을 골라 SCREEN별 카메라를 지정하고 저장하세요. 추가한 카메라는 각 분할의 빈 칸부터 채우고, 삭제·사용 안 함 카메라의 칸은 비웁니다. 카메라 번호·별명·접속 주소로 검색할 수 있으며 검색 중에는 순서 이동을 잠급니다. 각 영상 우클릭 → `이 화면의 카메라 지정`에서도 해당 분할의 배정을 바꿀 수 있습니다. 이미 같은 분할의 다른 칸에 있는 카메라를 선택하면 두 칸을 서로 바꿉니다. `이 화면 비우기`는 등록 목록을 삭제하지 않습니다.

HD/SD 선택은 ipTIME의 `/onvif1`·`/onvif2`를 전환합니다. 다른 형식의 RTSP 경로는 임의로 바꾸지 않습니다. 다른 기종은 기본 주소에 HD, 등록창의 `SD 전체 주소`에 저화질 스트림 주소를 입력하면 화질을 선택할 수 있습니다. 사용자 지정 경로에 SD 주소가 없으면 화질 메뉴를 비활성화합니다. 실제 지원 여부는 카메라에 따라 다릅니다. 전체 주소 입력 시 비밀번호의 특수문자는 URL 인코딩되어 있어야 합니다. IP / 도메인 방식에서는 자동 처리합니다. 별명은 최대 80자입니다.

## 단축키

CamFloat가 활성화되어 있을 때만 동작하며 등록·수정창에서는 입력을 방해하지 않도록 꺼집니다.

| 키 | 기능 |
| --- | --- |
| 1 / 2 / 4 | 화면 구성 |
| M | 선택 영상 음소거 |
| Ctrl+Shift+M | 모든 카메라 음소거 |
| Ctrl+R | 선택 영상 재연결 |
| Ctrl+M | 카메라 관리 |
| Ctrl+T | 항상 위 전환 |
| Ctrl+0 | 투명도 0%로 복원 |
| ← / → | 분할 확대 중 이전·다음 SCREEN, 기본 1분할에서는 이전·다음 사용 중인 카메라 |
| F11 | 선택 있음: 해당 화면 전체화면 / 선택 없음: 분할 전체화면 / 전체화면 중: 진입 전 창 상태 복원 |
| Alt / Alt+A | 앱 툴바 표시 |
| Esc | 확대 전 분할 복원, 이어서 전체화면 해제 |
| F1 | 사용법 / 단축키 |
| Alt+F4 | 종료 |

## 설정 저장

`%LOCALAPPDATA%\CamFloat\settings.json`에 저장합니다. 기본·SD RTSP 주소는 Windows DPAPI로 암호화하므로 같은 Windows 사용자 환경에서 사용하세요. 이전 4칸 설정은 새 카메라 목록으로 자동 이전하며 첫 저장 전에 `settings-v1.backup.json`을 남깁니다. 새로 만드는 주소 백업도 암호화합니다.

임시 파일에 쓴 후 원자적으로 교체하며 직전 정상 저장은 `settings.backup.json`에 보관합니다. 파일 손상 시 직전 백업을 복구하고 손상 원본은 `settings-damaged-*.json`에 보존합니다. 복구할 백업이 없으면 원본을 보존하고 새 설정으로 시작하며 안내합니다. 모니터 변경으로 창이 화면 밖에 있으면 시작할 때 화면 안으로 이동합니다. 오류 기록의 RTSP URL은 인증·쿼리 토큰까지 가립니다.

## 빌드·검증

`build.bat`이 의존성을 설치하고 `CamFloat.spec`으로 빌드합니다. 이 spec은 Windows 기본 ICU와 충돌하는 외부 도구의 ICU DLL이 포함되지 않도록 처리하므로 반드시 spec으로 빌드하세요.

```text
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe tests\network_qa.py
release\CamFloat\CamFloat.exe --self-check --demo-video sample-test.mp4
```

자체 점검 결과는 `%LOCALAPPDATA%\CamFloat\startup-check.json`에 기록합니다. `--self-check`는 사용자 카메라를 연결하거나 설정을 바꾸지 않습니다. `--self-check --demo-video 로컬동영상경로`로 네 영상 동시 재생과 항상 위 전환 중 재생 유지를 점검할 수 있습니다.

네트워크 QA는 FFmpeg·MediaMTX를 테스트 서버로 사용해 네 화면 영상 출력·확대 및 두 종류 전체화면 중 연결 유지·서버 중단·복구·연속 재생·GUI 응답을 확인합니다. 첫 실패 후 수동 재연결은 별도의 VLC 로컬 서버로도 확인합니다. 실제 카메라 주소나 기존 설정은 사용하지 않습니다. `CAMFLOAT_DATA_DIR` 환경 변수로 별도 설정·검증 폴더를 지정할 수 있습니다. 최신 변경·점검은 `CHANGELOG.md`와 `CODE_REVIEW.md`, 로그는 고정 경로 `verification\current`에 있습니다.
