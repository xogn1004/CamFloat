# CamFloat 사용 안내

RTSP 카메라를 1·2·4분할로 보는 Windows용 플레이어입니다.

## 시작하기

1. [다운로드](https://github.com/xogn1004/CamFloat/releases/latest)에서 `CamFloat-1.0.0-win-x64.zip`을 받습니다.
2. 압축을 모두 풀고 `CamFloat.exe`를 실행합니다. VLC는 별도로 설치하지 않아도 됩니다.
3. **카메라 관리 → 카메라 추가**에서 연결 정보를 입력하고 **추가**를 누릅니다.
4. 관리창에서 **저장**을 누르면 재생을 시작합니다.

`CamFloat.exe`와 `_internal`, `licenses` 폴더를 함께 보관하세요. 업데이트할 때는 앱을 종료하고 새 ZIP을 풀어 실행하면 됩니다. 카메라 목록과 설정은 유지됩니다.

현재 EXE에는 코드 서명이 없어 Windows에서 ‘알 수 없는 게시자’ 등의 경고가 표시될 수 있습니다. 배포 파일은 위 저장소의 Releases에서 받으세요.

### 첫 실행과 기본값

- 첫 실행에는 바탕화면 바로가기와 작업 표시줄 고정을 선택하거나 건너뛸 수 있습니다. 관리자 권한은 요청하지 않습니다.
- 작업 표시줄 고정은 지원하는 Windows에서 확인 창을 거칩니다. 프로그램 폴더를 옮기면 바로가기도 다시 만들어야 합니다.
- 처음에는 **1분할 · 항상 위에 꺼짐 · 투명도 20% · 하드웨어 가속 켜짐**입니다. 새 카메라는 **HD · 음량 100% · 음소거 해제**로 시작합니다.

## 화면 조작

| 동작 | 사용법 |
| --- | --- |
| 창 이동·크기 조절 | 영상을 드래그해 이동하고 창 가장자리를 드래그해 크기 조절 |
| 앱 도구 표시 | 상단 중앙에 마우스를 올리거나 Alt |
| 화면별 메뉴 | 영상에 마우스를 올리거나 우클릭 |
| 화면 선택·해제 | 영상을 클릭. 선택된 화면을 다시 클릭하면 해제 |
| 분할 전환 | 상단 1·2·4 버튼. 이미 2분할이면 2 버튼으로 좌우·상하 전환 |
| 한 화면 크게 보기 | 분할 화면에서 영상 더블클릭. 다시 더블클릭하면 복원 |
| 분할 그대로 전체화면 | 상단 전체화면 버튼 |
| 한 화면을 전체화면으로 | 해당 화면 선택 후 F11 또는 트리플클릭 |
| 기본 1분할 전체화면 | 영상 더블클릭. 다시 더블클릭하면 해제 |

확대해도 다른 화면의 연결과 소리는 유지됩니다. 확대 중 방향키는 이전·다음 SCREEN으로, 기본 1분할에서는 이전·다음 카메라로 이동합니다.

Esc는 확대를 먼저 해제하고, 한 번 더 누르면 전체화면을 종료합니다. 기본 1분할에서 시작한 전체화면은 Esc 한 번으로 종료합니다.

다른 앱으로 이동하면 화면 선택을 해제합니다. 1분할과 한 화면을 크게 보는 전체화면에서는 선택 테두리를 표시하지 않습니다. 상단 도구는 마우스가 떠난 뒤 약 1.6초 후 숨겨집니다. 아이콘 설명은 마우스를 잠시 올리면 볼 수 있습니다.

## 카메라 방향 조작 · 1.1.0 후보

영상 하단의 **카메라 이동** 아이콘 또는 우클릭 메뉴의 같은 항목을 누릅니다.

- 화살표를 짧게 누르면 조금 이동하고, 길게 누르면 이동을 이어갑니다. 손을 떼면 길게 누르기 반복을 멈춥니다.
- 작은 화면은 네 방향을 가로 한 줄로, 넓은 화면은 십자로 표시합니다.
- Esc·바깥 클릭·다른 앱으로 전환하면 패널을 닫고 반복 조작을 멈춥니다.
- 클릭은 대기 중인 요청 최대 5개까지 저장하고 0.6초마다 하나씩 처리합니다. 가득 찬 뒤의 클릭은 무시합니다.
- 길게 누르면 기존 대기 요청을 먼저 처리한 뒤 0.6초마다 이동을 요청합니다. 그전에 손을 떼면 반복 이동을 시작하지 않습니다.
- 방향을 바꾸면 이전 방향의 대기 요청을 지웁니다. 조작창을 닫거나 다른 앱으로 전환해도 남은 대기 요청을 지웁니다.
- 카메라 관리의 방향 조작 표시는 `지원 / 알 수 없음 / 미확인 / 앱 미지원`으로 구분합니다. 관리 화면을 열면 사용 중인 내부망 카메라의 제어 정보를 다시 조회하며, 실제 렌즈를 움직이지는 않습니다.

현재는 **내부망 IP로 등록한 카메라**를 대상으로 하며 ipTIME C500GS·펌웨어 37.0.161에서 확인했습니다. 다른 모델은 지원 여부가 다를 수 있습니다. 기존 방향키의 화면·카메라 전환 기능은 그대로입니다.

현재 후보는 이동 속도와 손 뗀 뒤의 움직임을 확인 중입니다. 손을 떼면 앱의 추가 요청은 중단하지만 카메라가 이미 받은 요청은 실행될 수 있습니다.

제어 정보는 처음 조회해 이 PC에 보관합니다. 목록 파일에는 넣지 않고, 불러온 카메라를 저장하면 새로 조회합니다.

## 소리·화질·투명도

- 스피커 버튼을 누르면 해당 영상만 음소거합니다. 작은 화면에서는 스피커에 마우스를 올려 세로 음량 조절 막대를 엽니다. 마우스 휠로도 조절할 수 있습니다.
- 음량을 조절하면 해당 카메라의 음소거가 풀립니다. 음량 0은 × 스피커로 표시합니다.
- **전체 음소거**는 모든 소리를 잠시 끕니다. 해제해도 개별 음소거 설정은 유지합니다.
- **HD/SD**는 카메라가 제공하는 영상 중에서 고릅니다. SD 주소가 없는 카메라는 SD를 선택할 수 없습니다.
- **항상 위에**를 켜면 다른 앱 위에 표시합니다. **전체 투명도**로 창을 비치는 정도를 조절합니다.
- 전체화면은 투명도 0%로 표시합니다. 전체화면에서 바꾼 투명도는 창 모드로 돌아오면 적용합니다.

## 카메라 추가·관리

**Ctrl+M** 또는 상단 카메라 아이콘으로 관리창을 엽니다.

- **간편 입력:** IP/도메인·포트·아이디·비밀번호를 입력합니다. 주소 칸에 `주소:포트`를 붙여넣어도 됩니다.
- **RTSP 주소:** 전체 주소를 붙여넣습니다. **고급 설정**에서 HD/SD 영상 경로와 SD 주소를 지정할 수 있습니다. 경로는 카메라 제조사 안내를 참고하세요.
- **연결 확인:** 입력한 정보로 영상 수신이 가능한지 확인합니다. 이 버튼을 누르지 않아도 등록할 수 있습니다.
- 목록에서 카메라를 고르고 **⋯**로 수정·사용 여부 변경·삭제를 합니다. 위·아래 버튼으로 목록 순서를 바꿉니다.
- 변경은 관리창의 **저장**을 눌러 적용합니다. 저장하지 않고 닫으려 하면 저장 여부를 확인합니다.
- 자세한 설명은 **ⓘ**를 클릭하거나 마우스를 올려 확인하세요.

### 화면별 카메라

카메라 번호와 SCREEN 번호는 별개입니다. **화면별 카메라** 탭에서 각 화면에 표시할 카메라를 고릅니다.

- 1·2·4분할마다 배정을 따로 저장합니다. 2분할의 좌우·상하는 같은 배정을 사용합니다.
- 영상 우클릭 메뉴에서도 그 화면의 카메라를 바꿀 수 있습니다.
- **사용 안 함**으로 바꾸면 모든 분할에서 빠지고 화면을 비웁니다. 다시 사용하면 각 분할의 빈 화면부터 채웁니다.
- **화면 비우기**로 특정 화면을 비워둘 수 있습니다.

### 연결 정보 확인·복사

주소·아이디는 처음에 숨겨져 있습니다. 입력칸의 눈·복사 아이콘을 사용하세요. **비밀번호·RTSP 주소를 보거나 복사할 때는 Windows 본인 확인이 필요합니다.**

확인한 정보는 30초 후, 다른 앱으로 이동하거나 카메라·탭을 바꾸면 다시 숨깁니다. 복사한 내용도 30초 후 지우며, 그 사이 다른 내용을 복사했다면 지우지 않습니다.

### 목록 내보내기·불러오기

관리창 상단 **⋯ → 목록 내보내기… / 목록 불러오기…**를 사용합니다.

- 이름·HD/SD 주소와 로그인 정보·순서·사용 여부·기본 화질을 저장합니다. 음량·음소거·화면 배정·창 설정은 포함하지 않습니다.
- 내보내기에는 Windows 본인 확인이 필요합니다.
- 불러올 때는 추가할 항목을 고릅니다. 중복은 제외하고 기존 목록은 유지합니다. **저장**을 눌러 적용하세요.
- 새로 불러온 카메라는 음량 100%·음소거 해제로 시작합니다.

**`.camfloat` 파일에는 접속 정보가 들어 있습니다. 별도 파일 비밀번호 없이 다른 PC의 CamFloat로 열 수 있으니 신뢰하는 사람에게만 전달하세요.**

### 삭제·초기화

관리창 상단 **⋯**에서 선택하고, 관리창의 **저장**을 눌러 적용합니다.

| 메뉴 | 적용 범위 |
| --- | --- |
| 카메라 전체 삭제… | 카메라 목록을 모두 삭제. 확인창에서 내보내기로 먼저 백업 가능 |
| 설정 초기화… | 카메라 목록·연결 정보·순서·사용 여부는 유지하고 음량·화질·화면 배정·앱 설정을 기본값으로 복원 |

설정 초기화 후 다음 실행에는 바로가기 선택창을 다시 표시합니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| 1 / 4 | 1분할 / 4분할 |
| 2 | 2분할로 전환 / 이미 2분할이면 좌우·상하 전환 |
| F11 | 선택 화면 전체화면 / 선택이 없으면 분할 전체화면 / 전체화면 종료 |
| Esc | 확대 복원 → 전체화면 종료 |
| ← / → | 확대 중 SCREEN 이동 / 기본 1분할에서 카메라 이동 |
| M | 선택 영상 음소거 / 해제 |
| Ctrl+Shift+M | 전체 음소거 / 해제 |
| Ctrl+M | 카메라 관리 |
| Ctrl+R | 선택 영상 다시 연결 |
| Ctrl+T | 항상 위에 / 해제 |
| Ctrl+0 | 창 모드 투명도를 0%로 변경 |
| Alt / Alt+A | 상단 도구 표시 |
| F1 | 사용법 / 정보 |

단축키는 CamFloat에서 작업할 때 동작합니다. 카메라 입력창에서는 입력을 방해하지 않도록 앱 단축키를 잠급니다.

## 연결이 안 될 때

주소·포트·아이디·비밀번호와 카메라 전원을 확인한 뒤 **다시 연결**을 누르세요. 처음부터 연결에 실패한 경우에는 자동으로 재시도하지 않습니다. 재생 중 끊겼다면 자동으로 재연결합니다.

카메라가 RTSP를 제공해야 사용할 수 있습니다. 제조사 앱에서 정상 재생되더라도 RTSP 사용 설정이나 경로가 따로 필요할 수 있습니다.

문제가 계속되면 [문제 신고](https://github.com/xogn1004/CamFloat/issues)에 앱·Windows 버전, 카메라 모델과 재현 순서를 알려주세요. 실제 접속 정보나 설정·내보내기 파일은 올리지 마세요.

설정 저장 위치와 진단 기록은 [개발 안내](development.md), 정보 보호 범위는 [보안 안내](../SECURITY.md)에 정리되어 있습니다.
