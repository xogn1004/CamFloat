# 검토·검사 요약

## 1.1.1-dev.1 · 스크린샷

- 화면별 자동 크기 조정: SCREEN이 960×540 이상이면 버튼·아이콘·슬라이더·방향 패널·배지·별명을 모두 약 1.5배로 표시합니다. 가로 900 미만 또는 세로 500 미만에서 원래 크기로 복원합니다. Windows 배율을 중복 적용하지 않습니다. 소수점 배율의 배치는 정수 픽셀로 반올림하며 실제 여백·도구 폭으로 전체 폭을 계산합니다.
- 크기 조정 후 작은 화면·큰 화면·가로만 긴 화면을 Qt로 렌더링해 배치를 확인했습니다. 저장 알림과 상단 도구 아래 배지 위치도 함께 조정했습니다. 이번 크기 조정에서는 자동 검사나 EXE 빌드를 추가로 실행하지 않았습니다.
- 상단 도구는 현재 표시하는 SCREEN 도구가 확대될 때 270×36에서 405×54로 함께 확대합니다. 분할 후 각 SCREEN 도구가 작으면 상단도 작게 유지하며, 확대 뒤에 숨겨진 SCREEN의 크기는 판단에서 제외합니다. 버튼·아이콘·간격·여백과 마우스 표시 영역을 1.5배로 맞췄습니다. 크기 변경으로 드러난 영상 영역을 다시 그리고, 배지가 도구에 가려지지 않게 배치합니다. 두 크기의 Qt 렌더링을 확인했습니다.
- SCREEN 도구와 우클릭 메뉴에 영상만 PNG로 저장하는 기능을 추가했습니다. 앱 메뉴와 저장 알림에서 사진/CamFloat 폴더를 엽니다.
- 저장은 재생 작업에서 처리해 화면을 막지 않습니다. 저장 중 카메라 변경·재연결·종료 시 플레이어 수명을 보호하며, 저장 실패가 재생을 끊지 않습니다. 파일명에는 카메라 이름·주소·계정 정보를 넣지 않습니다.
- 합성 영상으로 원본 해상도 PNG·연속 저장·실패 처리·재생 유지·종료 처리·최소 4분할 도구 배치를 확인했습니다. 스크린샷 검사 13개와 기본 검사 11개가 통과했습니다. 실제 카메라 영상은 저장하지 않았습니다.
- 기능 확인은 `tools/run-dev.bat`으로 먼저 진행합니다. 이번 단계에서는 EXE 빌드와 전체 QC를 실행하지 않았으며 정식 1.1.0 배포 파일을 유지합니다.

## 1.1.0 정식 릴리즈

사용자가 최종 EXE 확인을 완료했습니다. 실행 코드와 아이콘의 빌드 커밋은 `dc39138`이며, 이후 공개 상태 안내만 문서에서 갱신했습니다. 1.0.0 릴리즈는 유지합니다.

### 확정 아이콘·사용 안내 반영

- 사용자가 확정한 확대 아이콘을 PNG·ICO와 EXE에 함께 반영했습니다.
- README·변경 내역·사용 안내·앱 도움말·릴리즈 설명에서 처리 주기와 대기열 등 내부 설명을 제거했습니다. 연결 입력값·단축키·정보 보호 안내는 유지했습니다.
- 재생·방향 조작 로직은 변경하지 않았습니다. 빠른·시작 검사 21개와 압축 해제 EXE, 일반 시작 경로의 합성 영상 4개 재생을 확인했습니다. 전체 QC와 장시간 네트워크 검사는 반복하지 않았습니다.

### 이번 수정

- 앱 코드 `src/camfloat`, 자산 `assets`, 빌드 설정 `packaging`, 개발 도구 `tools`로 분리했습니다. 루트 일반 파일은 57개에서 10개로 줄였습니다.
- 패키지 import, `python -m camfloat` 진입점, PyInstaller·DLL·아이콘 경로, 검사·수동 도구 경로를 함께 변경했습니다. 현재 작업 폴더에 의존해 아이콘을 찾지 않습니다.
- 승인한 원본 PNG와 ICO를 함께 보관합니다. 일반 빌드에서는 ICO를 다시 만들지 않습니다.
- 1분할은 화면을 비울 수 없습니다. 비어 있으면 사용 가능한 첫 카메라를 지정하고, 현재 카메라 삭제·사용 해제 시 목록의 다음 카메라로 순환합니다.
- 2·4분할의 빈 SCREEN은 확대하지 않으며 확대 중 좌우 이동에서도 건너뜁니다. 연결 실패 상태라도 카메라가 배정된 SCREEN은 건너뛰지 않습니다. 확대된 SCREEN을 비우면 다음 배정 화면으로 넘어가고, 전부 비면 분할로 복원합니다.
- 엔진 초기화는 별도 작업에서 진행하고 시작 창을 먼저 표시합니다. 시작 중 이동·최소화·종료를 처리합니다. 엔진 자체의 첫 로딩 대기는 환경에 따라 남을 수 있습니다.
- 오래된 수동 데모·1.0.0 전용 요약 생성 스크립트 4개를 제거하고 현재 검사·실행 진입점으로 통일했습니다. 과거 카메라 조사는 `docs/research/`로 분리했습니다.

### 확인 범위와 제한

- 자동 검사에는 합성 영상·가짜 카메라·격리 설정을 사용했습니다. 이번 정리 중 실제 카메라 이동·음성 전송·휴대폰 통신·Windows Hello 입력은 새로 실행하지 않았습니다.
- 기존 실물 확인: 사용자가 ipTIME C500GS·펌웨어 37.0.161에서 내부·외부 방향 조작을 확인했습니다. 이 PC의 Windows 본인 확인도 사용자 확인 기록이 있습니다. 다른 장비·환경의 성공을 보장하는 결과는 아닙니다.
- 설정은 Windows 계정에 연결해 암호화합니다. 목록 파일에는 접속 정보가 포함되므로 신뢰하는 사람에게만 전달해야 합니다. 목록 파일은 별도 비밀번호 없이 다른 CamFloat에서 열 수 있는 설계입니다.
- 공개 전 Git 이력·문서 링크·배포 파일·외부 라이브러리 고지와 대응 소스를 검사합니다. 실제 접속 정보·로컬 설정·시험 영상·조사 APK는 공개 파일에 포함하지 않습니다.
- 중간 폴더 삭제는 자동 승인 검토에서 차단되어 사용자에게 범위가 정해진 PowerShell 스크립트를 제공했습니다. 사용자가 실행한 정리 기록에서 옛 개발·RC 파일 등 17개 경로 삭제를 확인했습니다.

세부 명령과 현재 폴더 구조는 [개발 안내](development.md), 남은 기능은 [후속 개발 계획](post-release-plan.md)을 참고하세요. 이전 버전별 검사 기록은 Git 이력에서 확인할 수 있습니다.
