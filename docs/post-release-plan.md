# 후속 개발 계획

1.1.0에는 상하좌우 방향 조작을 포함합니다. 다음 기능은 별도 검토 대상입니다.

| 기능 | 상태 |
| --- | --- |
| 소리 증폭 150~200% | 검토 예정. 작은 소리 확대와 왜곡·잡음의 영향을 확인해야 합니다. |
| 렌즈 숨기기·복원 | 조사 보류. 제조사 앱의 OFF/ON은 전원 차단과 다를 수 있습니다. |
| 저장 위치로 이동 | 조사 보류. 지원 명령과 실제 동작 확인이 필요합니다. |
| 카메라 스피커로 말하기 | 조사 보류. 전송 응답은 받았으나 실제 청취 성공은 확인하지 못했습니다. |
| 움직임·사람·울음 알림 | 후순위 |
| 줌 | 현재 개발 대상에서 제외 |

일반 수정에는 관련 기능의 간단 검사를 사용하고 전체 QC는 릴리즈 직전에 진행합니다.

기존 제조사 앱·ONVIF 조사와 수동 시험 기록은 [카메라 제어 조사 기록](research/camera-control.md)에 보관합니다.
조사 기록의 과거 주기·개발 버전은 현재 동작과 다를 수 있습니다. 현재 동작은 [사용 안내](user-guide.md)를 따릅니다.
