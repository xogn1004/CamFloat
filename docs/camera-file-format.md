# CamFloat 카메라 목록 파일

사용자 결정: 파일 비밀번호 없이 `.camfloat` 파일로 내보내고 불러온다.
파일을 가진 사람이 CamFloat로 열 수 있는 공유 형식이다. 파일 공유 대상은 사용자가 정한다.

## 형식과 범위

- 헤더: `CamFloat` + NUL + 버전 바이트 1.
- 암호화: cryptography AES-GCM, 공통 앱 키 256비트, 파일마다 새 12바이트 난수 nonce. 헤더를 인증 데이터로 사용.
- 내부: UTF-8 JSON, schema version 1, 최대 256대/파일 4MiB.
- 포함: 목록 순서, 이름, HD/SD 주소(로그인 정보 포함), 사용 여부, 화질, 개별 음량·음소거.
- 제외: Windows DPAPI 암호문, 사용자 PC 경로, 창 위치, 화면별 배정, 진단·영상.
- 앱 내장 공통 키는 앱/소스 보유자가 알아낼 수 있다. 파일 내용이 평문으로 바로 보이는 것을 막는 용도이며 앱 보유자에 대한 접근 제한을 보장하지 않는다. 암호화·태그가 송신자 신원을 보장하지 않으므로 복호화 후에도 입력을 검증한다.
- 호환되는 파일을 계속 불러오려면 공통 키를 유지한다. 키/형식 변경은 새 형식 버전과 구버전 읽기를 함께 제공해야 한다.

## 내보내기와 불러오기

- 내보내기는 Windows 본인 확인 뒤 실행한다. 읽을 수 없는 카메라가 있으면 조용히 누락하지 않고 내보내기를 중단한다.
- JSON 평문을 디스크에 쓰지 않고 메모리에서 암호화한 뒤 QSaveFile로 저장한다. 파일 비밀번호 창은 없다.
- 불러오기는 파일 크기·형식·태그·항목 형식·URL을 검증한 뒤 이름·사용 여부만 미리 보여준다. 미리보기에서 네트워크 연결을 시작하지 않는다.
- 동일 호스트·포트·경로·쿼리·아이디의 카메라는 중복으로 제외한다. 기존 카메라를 덮어쓰지 않는다.
- 선택한 새 항목은 새 식별자와 번호로 현재 관리창에 추가한다. 사용 안 함 카메라는 화면에 채우지 않는다. 취소하면 기존 목록을 유지한다.
- 관리창의 저장 전에는 실제 설정·재생에 적용하지 않는다. 저장하면 로컬 정보는 기존 Windows DPAPI 보호를 적용한다.

## 검증

왕복, 평문 비노출, nonce 변경, 파일 손상/절단/크기 제한, 암호화됐지만 잘못된 구조, 비정상 URL, 중복·번호·기존 목록 보존, 인증 전 파일 미생성, 불러오기 취소를 합성 데이터로 검사한다. 실제 사용자 설정이나 카메라에는 접속하지 않는다.
