# 카메라 목록 파일 형식

`.camfloat`는 카메라 연결 정보를 다른 CamFloat로 옮기는 공유 형식입니다. 별도 파일 비밀번호 없이 열 수 있으므로 앱 보유자에 대한 접근 제한을 제공하지 않습니다. 사용자 안내는 [목록 내보내기·불러오기](user-guide.md#목록-내보내기불러오기)를 참고하세요.

## 저장 구조

| 항목 | 내용 |
| --- | --- |
| 헤더 | `CamFloat` + NUL + 버전 바이트 1 |
| 암호화 | AES-GCM · 앱 공통 256비트 키 · 파일마다 새로운 12바이트 nonce · 헤더를 인증 데이터로 사용 |
| 내부 데이터 | UTF-8 JSON · schema version 1 |
| 제한 | 최대 256대 · 파일 4MiB |
| 포함 | 이름, 로그인 정보를 포함한 HD/SD 주소, 목록 순서, 사용 여부, 기본 화질 |
| 제외 | 음량·음소거, PC 전용 암호문·경로, 창 설정, 화면 배정, 진단·영상 |

공통 키는 사용자 비밀키가 아닙니다. 암호화는 파일 내용이 평문으로 바로 보이는 것을 막으며 송신자 신원을 보장하지 않습니다. 복호화한 입력도 검증해야 합니다. 키·형식을 바꿀 때는 형식 버전을 올리고 이전 파일 읽기를 함께 제공해야 합니다.

## 내보내기·불러오기

- 내보내기는 Windows 본인 확인 뒤 실행합니다. 읽을 수 없는 항목이 있으면 누락하지 않고 중단합니다. JSON 평문을 파일에 쓰지 않으며 암호화한 뒤 QSaveFile로 저장합니다.
- 불러오기는 크기·헤더·인증 태그·버전·항목 수·자료형·URL을 검증합니다. 미리보기에는 이름·사용 여부만 표시하고 네트워크에 연결하지 않습니다.
- 호스트·포트·경로·쿼리·아이디가 같은 항목은 중복으로 제외합니다. 기존 카메라를 덮어쓰지 않으며 선택한 항목에 새 식별자와 번호를 부여합니다.
- 이전 파일의 음량·음소거 값은 무시합니다. 새 카메라는 음량 100%·음소거 해제로 시작하고 기존 카메라의 소리 설정은 유지합니다.
- 추가는 관리창 초안에 반영합니다. 저장하기 전에는 실제 설정·재생을 바꾸지 않으며 취소하면 기존 목록을 유지합니다. 저장한 로컬 연결 정보에는 Windows DPAPI 보호를 적용합니다.

형식 검사는 `tests/test_camera_archive.py`에서 합성 데이터로 수행합니다. 왕복·nonce 변경·손상·크기·구조·URL 검증, 중복 제외, 이전 소리 값 무시와 기존 목록 보존을 확인합니다. 인증·취소·관리창 적용 흐름은 관련 관리 UI 검사에서 확인합니다.
