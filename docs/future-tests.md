# 추후 테스트 및 기능 검토

## 카메라 방향 회전·줌 제어

- 기록일: 2026-10-18
- 상태: 추후 테스트로 보류. 현재 기능 구현 및 실카메라 제어 테스트는 진행하지 않음.
- 대상 모델: ipTIME C400GS로 추정. 테스트 전 실제 모델명과 펌웨어 확인 필요.
- 목적: CamFloat에서 카메라 방향 회전과 확대·축소를 제공할 수 있는지 확인.

### 확인된 내용

- [공식 제품 설명](https://www.iptime.com/products/961)에 좌우 360°·상하 150° 회전과 저장 위치 이동(Preset)이 안내되어 있음.
- 제조사 앱의 회전 지원만으로 외부 ONVIF 회전·저장 위치 제어까지 지원한다고 확정할 수 없음.
- 광학 줌 지원은 확인되지 않음. 뷰어의 디지털 확대는 별도 기능으로 검토.

### 추후 확인 순서

1. 실제 모델명·펌웨어 및 ONVIF 서비스 주소·포트 확인. RTSP 주소의 포트와 같다고 가정하지 않음.
2. 카메라를 움직이지 않는 기능 조회로 PTZ 서비스·프로필·지원 명령 확인.
3. 실제 동작 테스트를 진행할 때 상하좌우 이동과 정지 확인. 버튼을 놓거나 포커스를 잃거나 조작 패널을 닫으면 정지하도록 검토.
4. 저장 위치 조회·이동 및 광학 줌 지원 여부를 각각 확인. 미지원 기능은 표시하지 않음.
5. 지원이 확인되면 화면별 작은 조작 패널을 검토. 기존 방향키의 화면·카메라 전환 동작과 충돌하지 않도록 구성.

접속 주소·계정·비밀번호는 이 문서에 기록하지 않음.
