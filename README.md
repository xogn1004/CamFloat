# CamFloat - RTSP Stream Viewer

Windows에서 RTSP 카메라를 1·2·4분할로 재생하는 작은 항상 위 플레이어입니다. **1.0.0 RC3 (`1.0.0-rc.3`)**.

## 실행과 배포

- 실행: `release/CamFloat/CamFloat.exe`
- 64비트 VLC media player가 필요합니다. 확인한 환경은 Windows 11 / VLC 3.0.23입니다.
- 배포할 때는 `_internal`과 `licenses`를 포함한 **CamFloat 폴더 전체**를 복사하세요.
- 실행 중인 기존 CamFloat를 종료한 후 새 실행 파일을 여세요. 메뉴 하단에서 버전을 확인할 수 있습니다.
- 카메라 설정은 `%LOCALAPPDATA%/CamFloat/settings.json`에 보관되며 별명·주소·계정은 Windows DPAPI로 암호화합니다. 배포 폴더에 사용자 설정을 넣지 않습니다.

## 카메라 관리와 정보 보호

- 관리 창은 **카메라 목록 / 화면 배정** 탭으로 나눕니다. 목록에는 번호·별명·화질·사용 상태만 표시합니다. 상세에는 이름 바로 아래 주소·아이디를 표시하며 재생 상태·SCREEN 배정 요약은 표시하지 않습니다.
- **비밀번호 / RTSP 주소 / RTSP 주소2 (SD)**는 반드시 Windows 본인인증 후 항목별로 30초 동안 확인합니다. 다른 앱 전환·Windows 잠금·선택/탭 변경·창 닫기 때 다시 가립니다. 입력한 값은 유지합니다. 기존 설정에서 본인인증을 꺼두었어도 민감 정보에는 필수 적용합니다.
- 수정·사용 안 함/다시 사용·삭제와 **RTSP 주소 / RTSP 주소2 (SD) 복사**는 목록의 **⋯** 메뉴에서 실행합니다. 별도 복사 버튼은 없습니다. 주소 복사도 본인인증이 필요하며 카메라에 접속하지 않습니다.
- 민감 정보 복사는 Windows 클립보드 기록·클라우드 동기화 제외 형식을 설정합니다. 30초 뒤 앱에서 복사한 항목이 그대로 있을 때만 지웁니다. 외부 프로그램의 사본까지 회수하지는 못합니다.
- 본인인증을 해제하는 메뉴는 없습니다. 지원 불가·취소·실패 때는 민감 정보를 공개하지 않습니다. 동일 사용자 권한의 악성 프로그램에 대한 방어를 보장하지 않습니다.
- 추가·수정 창은 **간편 입력 / RTSP 주소**를 지원합니다. 별명을 비우면 카메라 번호 기반 이름을 사용합니다. 기존 주소가 별명으로 사용된 경우 화면에서는 주소를 가립니다.
- **목록에 추가 / 변경 반영**은 관리 창 초안에 반영합니다. **저장하고 적용**을 눌러 최종 저장합니다. 미저장 변경 확인과 저장 실패 시 초안 보존을 지원합니다.
- 카메라는 **목록에 추가**로 한 대씩 등록합니다. 고급 설정은 **영상 경로 (HD) / 영상 경로 (SD)**로 표시하며, SD에는 `/onvif2` 같은 경로나 별도 RTSP 주소를 입력할 수 있습니다. 빈 주소나 입력 중인 주소에서도 간편 입력으로 돌아갈 수 있습니다.
- **연결 확인**을 누른 경우에만 별도 음소거 작업으로 영상 수신을 확인합니다. 취소·시간 제한을 지원하며 기존 플레이어 배정에는 영향을 주지 않습니다.
- 이전 백업·손상본도 보호된 형태로 보관합니다. 복호화 실패 카메라는 원본을 보존하며 연결하지 않습니다. 해당 PC/계정에서 복구하거나 **다시 입력**으로 교체할 수 있습니다.
- RC3 관리창 후속 정리에는 관리창 진입·입력 방식 왕복·인증 강제·인증 결과 처리·SD 경로의 집중 검사를 수행했습니다. Windows Hello 결과 처리는 모의 응답으로 검사했으며 실제 본인인증은 별도 확인이 필요합니다.

## 화면과 메뉴

- 프레임 없는 창을 마우스로 이동하고 가장자리에서 크기를 조절합니다.
- 상단 중앙에 마우스를 올리거나 Alt / Alt+A로 앱 도구를 표시합니다. 표시 영역을 벗어나면 약 **1.6초 후** 숨겨집니다. 앱 메뉴를 여는 동안에는 유지됩니다.
- 상단 순서: **1·2·4분할 | 전체 음소거 · 카메라 관리 · 전체화면 | 항상 위에 · 앱 메뉴**.
- 2분할 버튼과 단축키 2는 마지막 방향으로 전환합니다. 이미 2분할이면 좌우·상하 배치를 토글합니다. 버튼 아이콘은 저장한 방향을 표시하고 툴팁은 다음 동작을 안내합니다. 분할 변경 알림은 표시하지 않습니다.
- 앱 메뉴 순서: **화면 구성 → 전체 음소거/해제 → 카메라 관리 → 전체화면 | 항상 위에/해제 → 하드웨어 가속/해제 → 전체 투명도**.
- 작은 SCREEN에서는 스피커에 마우스를 올려 세로 음량 슬라이더를 엽니다. 스피커 클릭은 개별 음소거, 휠은 5%씩 음량 조절입니다.
- SCREEN 우클릭의 음량 메뉴는 음소거 메뉴 위에 있습니다.
- 전체 음소거는 별도 마스터 상태입니다. 해제해도 카메라별로 꺼둔 음소거는 유지됩니다.
- 전체화면에서는 **투명도 0%**로 고정됩니다. 전체화면에서도 투명도 설정을 바꿀 수 있으며 창 모드로 돌아오면 변경한 값을 적용합니다. 설정에는 `투명도 {설정값}% · 전체화면은 적용 안함`을 표시합니다.
- F1 또는 **사용법 / 정보**에서 사용법·단축키·기본 정보를 탭으로 확인합니다.

## 카메라 배정과 확대

- 카메라 번호와 SCREEN 번호는 별개이며, **1·2·4분할마다 배정을 따로 저장**합니다.
- 2분할의 좌우·상하 배치는 카메라 배정을 공유합니다. SCREEN 1은 왼쪽 또는 위, SCREEN 2는 오른쪽 또는 아래입니다. 방향 변경은 창 크기·카메라 연결·음량을 유지하고 위치만 바꿉니다. 방향은 재실행해도 유지합니다.
- 사용 안 함으로 바꾸면 모든 배정에서 빠지고 해당 화면을 비웁니다. 다시 사용하면 각 분할의 빈칸부터 채웁니다.
- 분할에서 더블클릭하면 그 SCREEN을 확대합니다. 다른 화면의 연결은 유지됩니다. 확대 중 방향키는 이전·다음 SCREEN으로 이동합니다.
- 기본 1분할의 더블클릭은 전체화면 전환입니다. 분할의 트리플클릭은 해당 SCREEN 확대 + 전체화면입니다.
- 선택된 화면을 다시 클릭하면 선택을 해제합니다. 다른 앱에서 돌아온 첫 클릭은 선택을 유지합니다. 1분할과 전체화면의 단일 확대에서는 선택 테두리를 표시하지 않습니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| 1 / 4 | 1분할 / 4분할 |
| 2 | 마지막 2분할 방향으로 전환 / 이미 2분할이면 좌우·상하 토글 |
| F11 | 선택 화면 전체화면 / 선택이 없으면 분할 전체화면 |
| Esc | 확대 복원 → 전체화면 해제 |
| ← / → | 확대 중 SCREEN 이동 / 기본 1분할에서 카메라 이동 |
| M | 선택 영상 음소거 / 해제 |
| Ctrl+Shift+M | 전체 음소거 / 해제 |
| Ctrl+M | 카메라 관리 |
| Ctrl+R | 선택 영상 다시 연결 |
| Ctrl+T | 항상 위에 / 해제 |
| Ctrl+0 | 창 모드에 사용할 투명도 0% 복원 |
| Alt / Alt+A | 상단 도구 표시 |
| F1 | 사용법 / 정보 |

단축키는 CamFloat에 포커스가 있을 때 동작합니다. 카메라 등록 창에서는 입력을 방해하지 않도록 앱 단축키를 잠급니다.

## 재생과 진단

첫 연결 실패는 수동 재시도만 허용합니다. 정상 재생 후 연결이 끊긴 경우에만 2~30초 간격으로 자동 재연결합니다. 450ms 버퍼 강제를 제거하고 VLC 기본 버퍼를 따릅니다. 일부 HEVC 카메라에서 발생했던 연결 당시 영상 고정은 이 변경으로 재현·복구를 확인했습니다.

익명 재생 통계는 `%LOCALAPPDATA%/CamFloat/diagnostics`에 크기를 제한해 기록합니다. 주소·계정·카메라 이름·영상은 기록하지 않습니다. 진단 출력 카운터가 증가하는 것만으로 영상 내용의 갱신까지 보장하지는 않습니다.

## 개발과 검증

Python 3.14 / PySide6 6.12 / python-vlc / PyInstaller를 사용합니다. 의존성은 `requirements.txt`에 고정했습니다.

- 빌드: `build.bat` (VLC는 별도 설치)
- 회귀 검사: `.venv/Scripts/python.exe -m unittest discover -s tests -p "test_*.py" -v`
- 네트워크 검사: `tests/network_qa.py` (로컬 MediaMTX·FFmpeg와 `verification/rtsp-keyframes-test.mp4` 검사 영상 필요)
- 시각 확인용 렌더: `tests/visual_qa.py`
- 검사 보고서: `CODE_REVIEW.md`. `verification/current/summary.json`은 RC1 당시 결과이며 RC2·RC3의 검사 결과가 아닙니다.
- 중간 파일 정리: `clean_intermediates.ps1`의 허용 목록만 삭제합니다. 소스·Git·개발 환경·최종 배포본·사용자 설정은 보존합니다.

일반 빌드는 과거 QA 결과를 복사하지 않습니다. 최종 배포 QA 요약은 해당 EXE의 자체 점검을 완료한 뒤 생성합니다. 변경 이력은 Git 커밋과 `CHANGELOG.md`로 관리합니다.
