# 후속 개발 계획

1.0.0 이후 검토할 기능입니다. 아직 제공하지 않으며 지원 범위와 일정은 검증 후 정합니다.

현재 우선순위는 **카메라 제어 지원 조사**입니다. 소리 증폭은 그다음에 검토합니다. 개발 버전과 기능별 간단 검사 명령은 [개발 안내](development.md)를 참고하세요.

## 소리 증폭

현재 최대 음량은 100%입니다. 작은 소리를 더 크게 들을 수 있도록 150%·200% 증폭을 검토합니다.

1. 합성 음원으로 실제 증폭량, 잡음 증가와 소리 찢어짐을 측정합니다.
2. 화면별 음량·음소거가 독립적으로 유지되는지, 확대·재연결 후에도 값이 유지되는지 확인합니다.
3. 기본 범위는 0~100%로 두고 증폭을 별도로 켤지 검토합니다. 100% 지점을 쉽게 구분하고 작은 슬라이더에서도 조절할 수 있도록 합니다.
4. 로컬 설정 저장·이전 설정 읽기와 필요시 출력 제한 처리를 함께 점검합니다. `.camfloat` 파일에는 계속 음량·음소거를 넣지 않습니다.

구현 검토: [libVLC DirectSound 출력 코드](https://github.com/videolan/vlc/blob/3.0.23/modules/audio_output/directsound.c).

## 카메라 제어

우선 검토 대상은 ipTIME C400GS이며 실제 모델·펌웨어와 외부 제어 지원 여부를 먼저 확인합니다. 제조사 앱에서 가능한 기능이 CamFloat에서도 가능한지는 별도 검증이 필요합니다.

| 기능 | 확인할 내용 |
| --- | --- |
| 방향 전환·저장 위치 | ONVIF PTZ 등 외부 인터페이스, 이동·정지·저장 위치 명령 |
| 확대·축소 | 광학 줌 지원 여부. 영상의 디지털 확대는 별도로 검토 |
| 촬영 켜기·끄기 | 사생활 보호 모드의 외부 제어 가능 여부. 실제 전원 차단과 구분 |
| 마이크로 말하기 | 음성 전송 경로·인증·지원 코덱·지연 |

### 확인·개발 순서

1. 실제 모델·펌웨어와 서비스 주소·포트를 확인합니다. RTSP 포트를 제어 포트로 가정하지 않습니다.
2. 기기를 움직이지 않는 기능 조회부터 진행합니다. 지원이 확인된 명령만 짧게 시험합니다.
3. 방향 제어는 버튼 해제·앱 전환·조작창 닫기·연결 끊김 때 정지하도록 설계합니다. 기존 방향키의 화면·카메라 전환과 충돌하지 않게 합니다.
4. 전원을 완전히 끈 기기는 외부 전원 제어 없이는 다시 켜지 못할 수 있습니다. 우선 사생활 보호 모드의 지원 여부를 조사합니다.
5. 마이크는 누르는 동안만 전송하는 방식부터 검토합니다. 대상 카메라와 전송 상태를 표시하고 버튼 해제·앱 전환·종료·연결 끊김 때 중단합니다.
6. 실제 지원이 확인된 기능부터 구현하고 기능별 검사를 진행합니다. 다음 릴리즈 직전에 전체 QC와 배포 EXE를 확인합니다.

참고: [ipTIME 제품 안내](https://www.iptime.com/products/961) · [RTSP 접속 안내](https://www.iptime.com/support/faq/26651) · [ONVIF Profile T](https://www.onvif.org/profiles/profile-t/).

시험 주소·계정·비밀번호와 실제 영상은 공개 문서·이슈에 기록하지 않습니다. 검사 운영 방식은 [개발 안내](development.md)에 정리했습니다.
