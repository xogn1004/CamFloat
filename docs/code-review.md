# 검토·검사 요약

## 1.1.0 최종 확인용 빌드

1.1.0은 GitHub 초안 릴리즈로 준비합니다. 공개 배포본 1.0.0은 유지하며, 사용자의 최종 EXE 확인 전에는 새 릴리즈를 공개하지 않습니다.

### 이번 수정

- 앱 코드 `src/camfloat`, 자산 `assets`, 빌드 설정 `packaging`, 개발 도구 `tools`로 분리했습니다. 루트 일반 파일은 57개에서 10개로 줄였습니다.
- 패키지 import, `python -m camfloat` 진입점, PyInstaller·DLL·아이콘 경로, 검사·수동 도구 경로를 함께 변경했습니다. 현재 작업 폴더에 의존해 아이콘을 찾지 않습니다.
- 원본 이미지와 사용자 제공 ICO를 보존했습니다. 일반 빌드에서는 ICO를 다시 만들지 않습니다.
- 1분할은 화면을 비울 수 없습니다. 비어 있으면 사용 가능한 첫 카메라를 지정하고, 현재 카메라 삭제·사용 해제 시 목록의 다음 카메라로 순환합니다.
- 2·4분할의 빈 SCREEN은 확대하지 않으며 확대 중 좌우 이동에서도 건너뜁니다. 연결 실패 상태라도 카메라가 배정된 SCREEN은 건너뛰지 않습니다. 확대된 SCREEN을 비우면 다음 배정 화면으로 넘어가고, 전부 비면 분할로 복원합니다.
- 엔진 초기화는 별도 작업에서 진행하고 시작 창을 먼저 표시합니다. 시작 중 이동·최소화·종료를 처리합니다. 엔진 자체의 첫 로딩 대기는 환경에 따라 남을 수 있습니다.
- 오래된 수동 데모·1.0.0 전용 요약 생성 스크립트 4개를 제거하고 현재 검사·실행 진입점으로 통일했습니다. 과거 카메라 조사는 `docs/research/`로 분리했습니다.

### 확인 범위와 제한

- 자동 검사에는 합성 영상·가짜 카메라·격리 설정을 사용했습니다. 이번 정리 중 실제 카메라 이동·음성 전송·휴대폰 통신·Windows Hello 입력은 새로 실행하지 않았습니다.
- 기존 실물 확인: 사용자가 ipTIME C500GS·펌웨어 37.0.161에서 내부·외부 방향 조작을 확인했습니다. 이 PC의 Windows 본인 확인도 사용자 확인 기록이 있습니다. 다른 장비·환경의 성공을 보장하는 결과는 아닙니다.
- 설정은 Windows 계정에 연결해 암호화합니다. 목록 파일에는 접속 정보가 포함되므로 신뢰하는 사람에게만 전달해야 합니다. 목록 파일은 별도 비밀번호 없이 다른 CamFloat에서 열 수 있는 설계입니다.
- 공개 전 Git 이력·문서 링크·배포 파일·외부 라이브러리 고지와 대응 소스를 검사합니다. 실제 접속 정보·로컬 설정·시험 영상·조사 APK는 공개 파일에 포함하지 않습니다.
- 중간 폴더 삭제는 자동 승인 검토에서 차단되어 사용자에게 범위가 정해진 PowerShell 스크립트를 제공했습니다. 사용자가 실행한 정리 기록에서 옛 개발·RC 파일 등 17개 경로 삭제를 확인했습니다.

세부 명령과 현재 폴더 구조는 [개발 안내](development.md), 남은 기능은 [후속 개발 계획](post-release-plan.md)을 참고하세요. 이전 버전별 검사 기록은 Git 이력에서 확인할 수 있습니다.
